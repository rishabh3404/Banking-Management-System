# 🏦 Banking Management System

A desktop-based Banking Management System developed using **Python**, **Tkinter**, and **MySQL**.

## 🚀 Project Status

🚧 Currently Under Development

---

## ✨ Features Completed

- 🔐 Secure Login System
- 🤖 CAPTCHA Verification
- 👤 User Type Selection
- 🛠️ Admin Dashboard
- 🏦 Open Account Module
- 📋 View Account Module
- ❌ Close Account Module
- 🚪 Logout System
- 📅 Live Date & Time

---

## 🛠️ Technologies Used

- Python
- Tkinter
- MySQL
- SQL
- VS Code
